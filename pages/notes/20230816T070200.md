## Better BibTeX 유물 — 설정과 삽질 (from 20250409T072408)

(“Better Bibtex for Zotero” n.d.)

한때 «LaTeX holdouts를 위한 필수 플러그인»이었다. 타입 커버리지, URI/RDF, 태그 export, translator 수정, citation key formula, postscript로 `dateadded=/=datemodified=/=callnumber` 를 bib에 심는 손까지 — 견고한 후처리 도구였다. 여전히 쓰는 사람은 많을 것이다. 힣은 과감하게 제거했다. 의존성을 떼기 어려웠으나, 지금은 키가 에이전트·손 편집 면으로 옮겨 GUI 없이도 산다.

### 원문 보존 — 2026-08-03 BBT 제거 선언

[[TIP("주의")]]
better bibtex는 이제 내가 안써. 에이전트가 bibcli가 이 기능을 다 자동화 커버하거든. 이건 사실 그 전시대의 유물이야. 다만 여기에 있는 설정 파일들 다 귀한 삽질이었다. zotero가 참 견고한 도구라. 서지를 담고 후처리해서 정리하는게 참 용이했어. 여전히 이거 쓰는 사람들 많을거야. 나는 언제인지 모르겠는데 과간하게 제거했어. 의존성을 때어내는게 어려웠지만 지금은 Citation Key를 에이전트 또는 내가 직접 편집해. 그 의미는 zotero gui를 켜지 않아도 된다는 거야.

gui 전용 플러그인은 여기 뿐만 아니라 어떠한 나의 툴도 허락하지 않아.

이것도 원문이야. 품고 가자. bib에 있을 노트가 아닌데 과거의 잔재다. 비우면 새로운 분을 모실 bib 노트다.
[[/TIP]]

### 타입 커버 (당시 메모)

artwork / audioRecording / bill / blogPost / book / bookSection / case / computerProgram / conferencePaper / dataset / dictionaryEntry / document / email / encyclopediaArticle / film / forumPost / hearing / instantMessage / interview / journalArticle / letter / magazineArticle / manuscript / map / newspaperArticle / patent / podcast / preprint / presentation / radioBroadcast / report / standard / statute / thesis / tvBroadcast / videoRecording / webpage / classic / gazette / legalCommentary / regulation / treaty

URI(RDF)만 있으면 도서 정보를 가져올 수 있다는 감각 — 메타 공백을 줄이려던 손. 한글 태그는 export가 안 되어 영어 태그로.

### Citation Key formula (Zotero 7 검증분, 2025-04-11)

prefix 감각은 지금 bibcli/pin 관례의 조상이다: `book-` / `blog-` / `wiki-` / `web-` / `doc-` / `person-` …

```text
type(book) + "book-" + shorttitle.lower() + shortyear;
type(blogPost) + "blog-" + "-" + shorttitle.lower() + shortyear;
type(encyclopediaArticle) + "wiki-" + shorttitle.lower();
type(film) + "film-" + shorttitle.lower() + shortyear;
type(document) + "doc-" + shorttitle.lower() + shortyear;
type(webpage) + "web-" + shorttitle.lower();
type(newspaperArticle) + "news-" + shorttitle.lower();
type(interview) + "person-" + shorttitle.lower();
type(dictionaryEntry) + "dict-" + shorttitle.lower();
type(artwork) + "art-" + shorttitle.lower() + shortyear;
shorttitle.lower() + shortyear
```

### Translator postscript (dateAdded 성스러움의 GUI 시대 해법)

«bib 파일에 callnumber를 넣지 마라»와 충돌하는 메모가 공존한다 — 삽질의 지층. 최종에 가깝던 형태:

```js
if (Translator.BetterBibLaTeX) {
  tex.add({ name: 'callnumber', value: zotero.callNumber});
  tex.add({ name: 'datemodified', value: zotero.dateModified});
  tex.add({ name: 'dateadded', value: zotero.dateAdded});
}
```

이 필드들을 지키려던 동기는 지금 [dateAdded 성스러움 autholog](https://notes.junghanacs.com/notes/20250409T142940/)와 같다. 수단만 GUI postscript에서 JSON sync·pin whitelist로 바뀌었다.

### 오독 주의

-   이 섹션을 «BBT를 다시 깔라»는 가이드로 읽지 않는다. 유물 보존이다.
-   키 포뮬러를 코드 본선에 하드코딩하지 않는다. 패턴 감각만 스킬/판단에 남긴다.

### <span class="org-todo done DONT">DONT</span> How to link Zotero Mdnotes and Emacs

이 작업의 시퀀스는? 목표는?!

조테로와 Emacs 사이에 작성 파일 접근 자유롭게. Markdown 포멧으로 통일. 필요한 플러그인 Mdnotes, Zotxt 으로. 이제 문서를 만드록 연결하여 읽을 수 있다.

-   Emacs
    -   아래를 보라. 예제 파일을 참고
    -   denote-type 으로 markdown-yaml 을 생성 -- Markdown 으로 파일
    -   reference 를 추가 한다. -&gt; citar 로 넣어주는 것이다.

-   조테로
    -   mdnote 를 연결하면 된다. 괜찮다.

Denote 문서로 만들어라. 의미 있는 시도이자 접근이다. 훌륭하다. 조테로 안쓸 수 없다. 노트는 형식을 불문한다.
